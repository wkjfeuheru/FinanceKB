## 必须保留的限制与方案缺口

1. **不是Gold、不是冻结集。** 自动构建题先进入silver候选池，全部等待人工审核。需要晋升Gold的题应按方案完成独立双人审核，不因本次脚本检查成功而自动通过。
2. **不是可直接运行的EvalCase schema 2.0。** 使用独立候选格式 `financekb-review-candidate-1.0`。真实入库 `chunk_id`、入库文档版本、结构化facts的同源证据组合、KB指纹尚未绑定。没有伪造chunk_id或把PDF页号当作块ID。
3. **引文偏移有明确坐标系。** JSONL的quote保存整页PyMuPDF抽取文本，`quote_start/end` 是该页Unicode文本的字符偏移，`page_text_sha256`用于验证；它们不是入库chunk文本的偏移。`document_version`为本地PDF SHA256版本标识，不能代替入库版本。机器映射未完成前不能声称满足schema 2.0证据门禁。
4. **时效题为限定集合的日期选择。** 每题写明观察截止日、候选文档、期望命中文档及日期，包含晚于截止日的干扰文件。没有同一公司多期完整原文，也未验证线上 `is_current`，因此仍缺真正同实体多版本时效测试。报告日期以封面/正文为准，不能用文件名日期替代。
5. **时间覆盖不足。** 已核实的精确报告日期集中于2026年8—9月；相对2026-10-31，缺少半年和一年以上的独立报告。引用的历史数据年份不能算作旧报告时间覆盖。精确日期尚未核实的文档在清单中为null，不强行归档。
6. **类别覆盖不足。** 包含个股、宏观、行业及技术白皮书；没有足够独立合规风控、运营、管理制度文件，也未读取线上知识库类别。因此不声称满足“投研≥70%、非投研≥20%”。虽然部分题涉及治理、供应商管理等内容，也不把主题标签冒充知识库类别。
7. **难度分布为30 easy / 42 medium / 30 hard。** 未强凑40/40/20：方案同时要求计算8%、多跳15%、时效7%，且都定义为hard，三项合计本就约30%。本批优先保留业务题型比例及真实难度，待审时可决定后续配额。
8. **拒答来源是核查线索。** 负样本 `evidence=[]`，页码与原文放在 `audit_references`。错误前提题有直接反证；超范围/未来实绩题限定为指定文件。不能用一页中没有某项信息证明整个线上知识库没有答案，所有拒答题都需人工确认其范围。
9. **不是独立保留测试集。** 和已有36题及历史题库共享文件、事实，部分是变式；未做跨集合事实去重或训练/验证拆分。后续若用于泛化评估，需按共享事实关联组或整篇文档隔离。
10. **只对文档忠实，不对现实真实性背书。** 文件中的预测、宏观叙述、报告测算按原文标注，未进行外部事实核验。参考答案不能直接视为当前投资建议。

## 人工审核重点

- 核对数值的公司、期间、单位、符号、预测/实际状态。中标不等于确认收入，预订不等于交付。
- M类题需要所有来源，不能拿一份文档替另一份作证；其中若干题是并列对比，并非严格的依赖式多跳推理。
- P类过滤条件是人工意图标注，未保证和当前索引字段枚举完全一致。冻结前应按真实索引元数据绑定。
- 国机汽车第1页汽车流通服务“70.1亿元、占比50.8%”与总营收口径存在不一致，本批未使用该组数值作为标准计算题；横店东磁第1页净利率表存在文字排版挤连，本批未以该表行出题。
- 机器证据采用完整页；审核稿的原文片段只帮助找到位置，不能替代阅读整页。PDF页码与页脚印刷页码可能不同，如IDC物理第30页对应印刷第28页。

人工审查完成后，仍需另行决定证据映射、冻结及是否运行评测。本次工作止于待审候选集。
