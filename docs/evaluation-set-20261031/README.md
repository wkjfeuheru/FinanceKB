## 保留的证据边界和覆盖缺口

- 所有答案以本地语料为准，不是对现实金融、政策或预测的外部认证。来源页码为PDF从1开始的物理页码，不等于页脚印刷页码。
- JSONL是financekb-review-candidate-1.0候选格式，不可声称已满足正式EvalCase schema 2.0。真实chunk_id、入库版本、结构化事实的同源证据组及KB指纹仍未绑定。quote是完整PyMuPDF页文本，quote_start/end为该页Unicode字符偏移，不是入库块偏移；document_version为本地PDF哈希标识。
- 18份本地PDF中使用16份。信科移动和GEO两份文字层乱码，本批未使用。已核实日期集中在2026年8—9月，半年及一年以上独立文档缺失；历史数据年份不算旧报告覆盖。
- 个股、宏观、行业和技术内容均有覆盖，但合规风控、运营、管理类独立材料不足，线上知识库类别未核验，不能声称满足方案全部类别配额。
- 本轮按用户要求增加计算题，原方案题型比例和40/40/20难度目标不再强凑。hard题增加，保留真实运算和多来源难度。
- 时效题仍缺同实体多版本完整语料，未验证线上is_current。事件时间、财务期间、报告发布日期分别标注，不混用。期望日期与来源属于答案侧标签，不能作为检索时的先验来源过滤器。
- 负样本evidence保持空数组，audit_references只提供反证或范围核查线索，不是全库无答案证明。问题不再指定文件，拒答判定针对本地语料快照，线上全库无答案状态尚未验证。未来实绩题统一以2026-11-01为观察日，未来使用时需复查。
- 与已有题库共享文件和事实，不是独立保留集；未进行跨集合事实隔离。多文档题包含并列对比，不全是严格依赖式多跳。
- 国机汽车汽车流通收入及占比、横店东磁净利率表的原文口径/排版问题仍避开；不可因引文匹配成功就把原文所有数字视为内部一致。
